## 仓库约定

每个实验对应一个分支，分支以 `labx` 命名（`lab1`、`lab2`、…）。每个分支的根目录包含两个文件夹：

- `code/` — 该实验实现后的源代码
- `report/` — 实验交付物：
  - `report.md` — 实验报告
  - `prompt.md` — 本实验全部提示词汇总
  - `images/` — 报告中引用的测试截图

`main` 分支仅保留本说明与 `.gitignore`，作为各实验分支的公共基点。
